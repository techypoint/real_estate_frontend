# Tasks

Status: `proposed` → `agreed` → `in-progress` → `done` (or `deferred` / `dropped`).
We pick one task, discuss it, agree on scope, then build it.
A task is `done` when its agreed scope ships; deferred follow-ups become their own tasks.

**Each task has its own file in [tasks/](tasks/)** — scope, checklist, open questions and a dated progress log.
Update that file as work happens; keep this index's status column in sync.
